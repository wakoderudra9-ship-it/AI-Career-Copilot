# 🚀 AI Career Copilot

An AI-powered career guidance platform designed specifically for students.

---

## 📖 Project Overview

AI Career Copilot helps students prepare for their careers by providing AI-powered tools for:

- 👤 User Authentication
- 📄 Resume Building
- 💼 Student Freelance Marketplace
- 🤖 AI Career Guidance
- 🎯 Job Recommendations
- 🎤 Interview Preparation
- 📊 Career Dashboard

---
